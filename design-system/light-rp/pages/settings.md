# Page: Settings

Overrides MASTER for the configuration workspace.

- Same tokens as Home. This is a labeled form, not a marketing page.
- Group fields with fieldset/legend: 模型接口, Nowledge Mem, 记忆容量, 对局与世界书, 路径.
- Every control has a visible label. Helper text sits under the field, never as the only prompt.
- API base URL is the first field. Do not assume OpenAI; placeholder is a generic `/v1` root.
- Password field for the key; GET never round-trips the secret. Save shows a status message.
- Header reuses Home chrome (wordmark, settings, theme). Back is a real link to `/`.
- Touch targets ≥44px. Save uses the accent button; secondary is 返回世界列表.
