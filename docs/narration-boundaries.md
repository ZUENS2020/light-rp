# 叙事前置层与模型拒绝处理

自由叙事工作区使用新的虚构小说创作约定，明确作者、统一叙事者、角色与文学表现的关系。它强调角色动机、因果和非操作性的情节描写，不声称模型提供方的协议或安全措施已经停用，也不保证模型接受任何请求。

为兼容原有设置，只有自由叙事模式下与继承的 Hermes 默认头部完全一致的模板会在组装时替换。自定义模板、明确空模板、普通叙事工作区、已冻结的任务上下文与历史资料保持原值。新头部为固定文本，角色与玩家宏仍仅替换一次；不增加额外模型调用。

模型传输识别 Chat Completions 的 `message.refusal`、`delta.refusal` 和 `finish_reason=content_filter`。这些是终态错误，已输出的可见内容保留为草稿，错误码为 `MODEL_REFUSAL`，不自动再次请求同一输出。响应中的推理字段和私有错误正文不会进入草稿或日志。

部分模型仅返回普通文本拒绝，因此叙事边界另作保守检查：必须同时具备未引用的拒绝开头及助手／请求层面的说明。此检查只用于叙事正文，不检查结构化抽取中的原句。它不是内容分类器，也不能保证识别所有拒绝。普通角色对白、带引号的拒绝、剧情中的助手台词不会仅因包含“不能”而被拦截。

拒绝在保存成功叙事产物和抽取之前停止。已有叙事产物及重放到验证步骤的产物也接受检查，防止恢复路径跳过边界。失败保留草稿、来源不增加、故事版本不推进、记忆任务不派发；用户可以查看说明后调整输入。

验证包括分块流、非流式和空拒绝字段、普通角色对白、结构化数据，以及持久工作流的草稿、单次模型调用、事件数量和 outbox 终态。真实模型对特定剧情的接受程度仍需实际测量，本次没有重试先前被提供方拒绝的输入。

2026-10-12 验证：`npm run check` 通过，包含 377 个单元测试、类型检查、构建与原有确定性评测；串行完整浏览器套件通过。浏览器日志仍有既有本地 Workflows 挂起取消提示及预期来源失效错误，通过结果不代表日志无异常。远端只读检查确认赛马娘为 freeform/revision 1，使用继承默认头部，故事仍为 55 条事件。本次不修改资料、剧情、模型直连配置或记忆策略。
