# 工作区自由叙事 · 2026-10-12

工作区提供规则约束（guided）与自由叙事（freeform）两种模式。默认沿用规则约束；左侧工作区名称旁的按钮可切换，启用时显示“自由”。该设置覆盖工作区内现有分支及以后新建的故事，不修改角色卡、世界书或历史正文。

自由叙事取消应用内的题材、文风、单回合推进幅度、角色行为、玩家代写及参考设定的叙事禁令。生成提示明确把原有全局提示、角色卡与世界书作为参考；末尾再次注入作者授权，覆盖这些资料中的叙事限制。语义验证收到同一个模式，硬规则列表为空，不再因正文违反参考资料或替玩家作决定而拒绝提交。

此设置不是模型提供方的限制开关，也不改变模型窗口、输出容量、身份认证、记忆原文证据、分支范围和删除规则。自由创作正文仍通过原有结构化记忆管线；不能以模式开关伪造原文或经历结果。

`GET /api/v3/worlds/:id/narrative-policy` 返回工作区和当前模式、版本。`PUT` 接受 `commandId`、`expectedRevision` 与 `mode`，按认证所有者读取，使用 D1 事务 guard 提交。`world_policy_changes` 保存变更记录。同一请求只执行一次，版本冲突返回 409。

每次生成冻结模式与版本；上下文组装结束和剧情提交时检查版本。切换期间迟到的旧生成不能提交新剧情，草稿保留供重试；历史上下文快照保持原样。其他工作区的规则与模式不变。

回归覆盖跨工作区隔离、现有分支与新故事、自由模式放行叙事冲突但拒绝假证据、旧快照保留、迟到提交整批回滚、版本冲突、其他所有者、幂等与恢复约束模式。浏览器验收覆盖切换、刷新后持久保存、生成提示／硬规则同步和恢复。

2026-10-12 验证：类型检查、367 项测试、构建及原有确定性评测通过；浏览器完整验收 13/13 通过。预览已应用迁移 0009 并部署，仅“赛马娘”启用自由叙事（策略版本 1），其他工作区保持规则约束。设置变更不新增剧情回合；此前失败任务需重试以读取新模式，旧错误和草稿保持原记录。
