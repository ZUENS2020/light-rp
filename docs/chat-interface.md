# 聊天滚动与消息来源

聊天区进入最新故事、切换分支或当前会话时定位到该视图末尾；历史分页从页首开始，返回最新剧情后定位到末尾。

只在用户仍靠近末尾时跟随流式正文。向上阅读后保持位置，后台刷新不打断阅读，并显示“回到最新”；此时新增正文会显示“有新内容”。主动发送、重试或点击返回按钮恢复跟随。滚动限定于正文容器，不调用会连带移动外层页面的 scrollIntoView。

浏览器原生滚动锚定被关闭，由显式跟随状态及尺寸观察控制。展开保存的草稿视为阅读动作，暂停跟随；窄屏默认关闭检查器，桌面缩窄时也收起覆盖正文的检查器。

消息以服务端角色字段区分：玩家发言右侧显示“你”及当前玩家身份，统一模型输出左侧显示“AI 叙事”，作者设定／纠正使用独立卡片与标签。生成中的正文和失败草稿明确标为未提交。AI 叙事可能包含多个角色，界面不从正文猜测单一发出角色。

## 验证

- 317 项单元用例、类型检查、构建和 128 项确定性记忆回放通过。
- 完整浏览器验收 11 项；新增用例交错注入大段消息与真实滚轮／键盘操作，验证首次到底、暂停／恢复跟随、5 秒刷新不移动、分页、窄屏重排、外层页面不滚动、展开草稿不跳走和来源布局。该用例控制事件注入以验证 UI；原有用例仍访问真实本地 Worker SSE。
- 最初并行运行构建与浏览器测试曾触发本地 Worker 重启，请求失败；已顺序运行并复测。

这是界面修改，不改变叙事提交、模型设置、记忆权限或玩家控制规则。
